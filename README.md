## Features

- **Interactive Freight Quote System:** Real-time load parameters capture with instant validation, pickup/delivery scheduling, and cargo weight limits.
- **TCPA / 10DLC SMS Compliance:** Explicit opt-in checkbox with legal disclaimers, message rate disclosures, and unbundled consent logging.
- **Direct Carrier Communications:** Click-to-call direct dialer integration (`tel:+16128871277`) and email dispatch routing.
- **Modern Responsive UI:** Designed with a corporate white-and-deep-blue palette, high-contrast dark mode, sticky shrinking navigation bar, and accessible keyboard navigation.
- **Full Legal Suite:** Comprehensive Carrier Service Terms and Conditions and strict 10DLC-compliant Privacy Policy.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Routing:** React Router v7
- **Icons:** Lucide React

## Development Setup

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Local Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your web browser.

3. **Production Build:**
   ```bash
   npm run build
   ```

4. **Lint and Type Check:**
   ```bash
   npm run lint
   ```
